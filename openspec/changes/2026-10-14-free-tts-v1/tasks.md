# free-tts v1 Implementation Plan

> **For agentic workers:** implement this plan with [[pavilio-execute-plan]] — task-by-task, top-down; check off each step (`- [ ]` → `- [x]`) as it lands. Do one task fully (test → implement → verify → commit) before starting the next.

**Goal:** Ship `free-tts@0.1.0` — Edge engine with its own client, cache, tiered scheduler, voice API and `free-tts/text` — usable from the browser and Node.

**Architecture:** Core entry `free-tts` (`createTts` → cache → scheduler → engine → transport or Relay), an independent `free-tts/text` entry and a `free-tts/server` Relay handler for non-Edge browsers. Pure TypeScript, ESM-only, zero runtime dependencies; every network edge sits behind an injectable transport so the suite runs on fakes.

**Tech Stack:** TypeScript, pnpm, vitest (`node` + `jsdom` projects), `tsc` build, GitHub Actions, npm.

**Design:** [design.md](./design.md)

**Preconditions (check before Task 1):** the pavilio 403 hotfix PR is merged (its Sec-MS-GEC v2 module is the source for Task 3), and motyl `fix/pronunciation-match-strictness` is merged to motyl `main` (source for Task 14). If either is open, start with tasks that don't depend on it and stop before 3 / 14.

### Task 10: createTts — synthesize, prefetch, join, retry, abort

**Files:**
- Create: `src/tts.ts` (`createTts`)
- Modify: `src/index.ts` (exports)
- Test: `src/__tests__/tts.test.ts` (fake engine)

**Contract:**
```ts
export interface SynthesisRequest { text: string; lang?: string; voice?: string; engine?: string; tier?: string; signal?: AbortSignal; }
export interface SynthesisResult { bytes: ArrayBuffer; mime: "audio/mpeg"; engine: string; voice: string; }
export interface TtsConfig {
  engines: Record<string, { voices: Record<string, string> & { default: string }; retries?: number } & EdgeEngineOptions>;
  defaultEngine: string; scheduler: SchedulerConfig; cache?: { max?: number };
}
export interface Tts {
  synthesize(req: SynthesisRequest): Promise<SynthesisResult>;
  prefetch(req: SynthesisRequest): void;
  isCached(req: SynthesisRequest): boolean;
  subscribe(listener: (e: { type: "add" | "evict"; key: string }) => void): () => void;
}
```

**Acceptance criteria:**
- WHEN `voice` is given THEN it is used; ELSE `voices[lang]`; ELSE `voices.default`; WHEN `lang` has no entry THEN `default`
- WHEN `voice` is not in the engine's catalog THEN it rejects `unknown-voice` and the engine is never called
- WHEN `engine` is omitted THEN `defaultEngine` serves it
- WHEN the same (engine, voice, text) is requested twice THEN the engine is called once (cache hit, or join while in flight); WHEN joined with a higher tier THEN the job is promoted
- WHEN an attempt fails transiently and `retries: 1` THEN one more attempt is made; WHEN it fails again THEN the last kind is rejected; WHEN the failure is non-transient THEN no retry
- WHEN a synthesis fails THEN nothing is cached and the next request calls the engine again
- WHEN the only caller aborts THEN the job leaves the queue / its engine signal aborts, and the caller rejects `AbortError`; WHEN one of two callers aborts THEN the other still resolves
- WHEN `prefetch` fails THEN no unhandled rejection is raised
- WHEN two instances are created THEN they share no cache

**Tests (names only — red first):**
- "voice resolution: explicit, then language map, then default"
- "foreign voice rejects unknown-voice without calling the engine"
- "default engine serves requests without engine"
- "duplicate requests call the engine once"
- "joining with a higher tier promotes the job"
- "transient failure retries up to the limit"
- "non-transient failure is not retried"
- "failures are not cached"
- "aborting the only caller cancels the job"
- "aborting one of two callers keeps the job"
- "prefetch swallows failures"
- "instances share no cache"
